# Control mapping to public guidance

Design inspiration only. This mapping is not a statement of conformance or certification.

| Public guidance area | Reference control / evidence | Remaining organizational work |
| --- | --- | --- |
| NIST AI RMF — Govern | Accountable mandate owner, approval roles, development and operating records | Risk appetite, policies, delegated authority, training, oversight |
| NIST AI RMF — Map | Declared purpose, tool/resource/environment scope and threat model | Context, affected stakeholders, real data and system dependencies |
| NIST AI RMF — Measure | Negative tests, scenario receipts, replay/concurrency and integrity checks | Real-world evaluations, independent review and operational monitoring |
| NIST AI RMF — Manage | Denial precedence, independent approval, budget and emergency stop | Incident response, recovery, risk acceptance and retirement |
| OWASP Agentic AI Security — tool misuse and privilege abuse | Explicit registry and grants, independent impact approval and connector boundary | Identity enforcement, credential isolation, actual connector tests |
| OWASP Agentic AI Security — agent behavior hijacking | Actions constrained independently of prompt prose | Broader prompt/retrieval defenses, goal monitoring and output validation |
| CISA / NCSC secure AI development | Threat model, narrow reference architecture, validation, provenance and documented limits | Secure operation, supply-chain and deployment engineering |

References, reviewed 9 October 2026:
